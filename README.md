## 🔨 What I'm working on

- **[ArcLock Project](https://github.com/ArcLockProject/mono)**: open source (MIT) React components and TypeScript libraries, published on npm.
  - [`@arclockproject/common`](https://www.npmjs.com/package/@arclockproject/common): draggable windows, a video/audio player, movable/zoomable elements, A* pathfinding, an audio manager and more.
  - [`@arclockproject/mmd-player`](https://www.npmjs.com/package/@arclockproject/mmd-player): an MMD loader and player for React, built on Babylon.js and babylon-mmd.
  - Docs with live, editable examples: [arclockproject.org](https://arclockproject.org)
- **[Kroniki Engine](https://github.com/ArcLockProject/kroniki)** (early development): a visual novel and story-driven RPG engine built with React and PixiJS, for the browser, desktop and Android. [Demo](https://kroniki.arclockproject.org/demo/) | [Guide](https://kroniki.arclockproject.org/)
